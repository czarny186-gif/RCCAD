Zasoby interfejsu RCCAD Desktop.

Oryginalne grafiki RCCAD.html: folder html/ oraz manifest html/catalog.json.
Ekstrakcja: native/scripts/extract_html_graphics.py. Grafiki nie uruchamiają HTML/JS;
SVG renderuje natywnie QtSvg. Wersje *.source.svg zachowują oryginalny fragment.

Folder fonts/ zawiera DejaVu Sans, Sans Bold i Serif oraz pełną licencję.
Obrazy PNG w katalogu głównym zachowano dla starszych elementów interfejsu 0.3.
